## ⚡ Key Features

- **Zero Heavy Dependencies:** Native HTML/SVG output for fast, high-performance rendering.
- **TypeScript First:** Fully typed props, formatters, and configuration interfaces.
- **Interactive Controls:** Built-in support for dropdown selection, custom charsets, length sliders, and error correction levels.
- **Native Export Utilities:** Direct clipboard copying and SVG/PNG download support built into components.
- **Pre-designed Templates:** Out-of-the-box components for conference ID badges, pass cards, and event tickets.

```bash
